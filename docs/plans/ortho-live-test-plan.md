# حزمة الاختبار الحي المُقيد — ortho-books-sync (S3-T3، بند 8)

> التاريخ: 2026-10-08 | **التشغيل الحي نفسه غير منفذ وممنوع دون تفويض** (العقد §2-Level C).
> هذه الحزمة تجعل التشغيل المفوض لاحقًا إجراءً واحدًا موثقًا لا ارتجالًا.

## لماذا التجميد حتى هذه الحزمة؟

قيمة المستودع تشغيلية لا بحثية، وتشغيله على محتوى محمي بلا مراجعة بشرية يخالف روح
الفلتر القانوني المدمج فيه (الجدول الخامس للمخاطر: خطر قانوني). المستودع خاص —
يبقى خاصًا خلال الاختبار وأ بعده.

## سيناريو الدورة الكاملة على قناة تجريبية معزولة

| الخطوة | الإجراء | معيار النجاح |
|---|---|---|
| 1 | قناة تيليجرام تجريبية جديدة يملكها المالك فقط (بلا مشتركين) | موجودة + مذكورة في سجل الاختبار |
| 2 | تغذية مصدر محدود: 10 مستندات من ثلاث فئات (كتاب مرجعي منشور رخصته متاحة / ملف المستخدم الخاص / مستند محمي حقوق معروف) | 10/10 وصلت |
| 3 | تشغيل دورة المزامنة الكاملة مرة واحدة | اكتمال بلا استثناءات غير معالجة |
| 4 | قياس الفلتر القانوني: المستند المحمي يُعلم ويُتخطى مع سبب في السجل | قرار فلتر صحيح 3/3 فئات |
| 5 | تدقيق المخرجات: لا تحميل مكرر، أسماء سليمة، سجل كامل | صفر شواذ |
| 6 | تقرير حي واحد: الأزمنة، الأخطاء، قرارات الفلتر، أي سلوك غير متوقع | ملف `docs/plans/ortho-live-test-result.md` بعد التشغيل |

## قائمة التحقق القانونية (قبل التفويض)

- [ ] تأكيد أن كل مصدر في قائمة الاختبار إما مرخص أو ملك المستخدم أو مقصود حجبه بالفلتر.
- [ ] القناة التجريبية خاصة وبلا أعضاء (صفر توزيع خارجي).
- [ ] لا احتفاظ دائم بأي ملف محمي حتى لو التقطه الفلتر (تخطى = حذف محلي).
- [ ] سجل الاختبار يبقى داخل المستودع الخاص، وتقرير النتيجة بصيغة مجردة (أرقام وقرارات، لا روابط محتوى).

## حزمة أوامر التنفيذ (تنفذ بعد التفويض فقط)

```bash
# 1) إنشاء القناة التجريبية يدويًا من حساب المالك (خارج الأتمتة عمدًا)
# 2) تشغيل الدورة المقيدة:
gh workflow run <sync-workflow> -R DrAbdulmalek/ortho-books-sync -f channel=<TRIAL_CHANNEL_ID> -f dry_run=false -f max_items=10
# 3) سحب السجل واعتماد تقرير النتيجة
```

## معيار إلغاء التجميد (بند 8 في المصفوفة)

تفويض مالك موثق (OD في القائمة) + اكتمال الجدول أعلاه 6/6 + تقرير نتيجة يُرفق
بتحديث الخطة الموحدة. أي فشل خطوة = عودة التجميد فورًا وتوثيق السبب.
