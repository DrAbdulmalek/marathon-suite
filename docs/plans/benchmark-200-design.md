# تصميم benchmark الـ 200 صورة (S3-T1، بند 6) — الوثيقة التصميمية

> التاريخ: 2026-10-08 | الهدف: أول قياس خارجي محايد للخط اليدوي الطبي العربي.
> الحدود: عينات مجهولة الهوية بالكامل، لا محتوى طبي حقيقي معرِّف، لا نشر قبل موافقة مالك.

## 1) التقسيم الطبقي (Strata) — 200 صورة

| الطبقة | العدد | الوصف | مصدر التوليد |
|---|---|---|---|
| مطبوع نظيف | 40 | وصفات/تقارير مطبوعة، جودة مسح عالية | رندر نصوص → PDF → مسح 300dpi |
| مطبوع متدهور | 40 | نفس المصدر + تشويش مسح (انحراف، ظل، تباين منخفض، JPEG) | تحويلات حتمية موثقة المعاملات |
| خط يدوي مقروء | 50 | خط يدوي عربي واضح (وِجهات من handwriting-notes/omni-handwriting-samples — بعد إخفاء الهوية) | عينات مجهولة + رندر خطوط رقمية |
| خط يدوي صعب | 40 | تداخل، هوامش ضيقة، تصحيحات يدوية فوق النص | عينات مجهولة مُنتقاة |
| مختلط | 30 | نموذج مطبوع + حقول مملوءة يدويًا (الحالة السريرية الأشيع) | قوالب + تعبئة |

قاعدة التوليد الحتمي (من درس golden-sample في ocr-core): رندر عبر libraqm/HarfBuzz
بخط مرفق داخل الحزمة (SIL OFL) لضمان قابلية إعادة التوليد بلا صور مخزنة حيث أمكن.

## 2) الحقيقة المرجعية المزدوجة

- مُدخلان مستقلان (A وB) لكل صورة، ثم حَكَم (C) يحسم الخلاف.
- الاختلاف يقاس بـ CER(A,B) — الفروق فوق عتبة موثقة تُحال للحكم إلزاميًا.
- ملفات GT بصيغة JSON موحدة (نص + لغة + ملاحظات)، ومجلدات `gt_a/gt_b/gt_final`.

## 3) المقاييس

| المقياس | التعريف | أداة التطبيع |
|---|---|---|
| CER | مسافة Levenshtein أحرف / طول المرجع | `arabic_strong_normalize` (نفس تطبيع ocr-core) |
| WER | كلمات خاطئة / إجمالي الكلمات | نفس التطبيع |
| دقة المصطلحات الطبية | نسبة المصطلحات (قائمة من arabic-medical-glossary) الصحيحة حرفيًا | قائمة مغلقة موثقة الإصدار |

كل رقم ينشر مع: نسخة المحرك، إصدار النموذج، معاملات المعالجة المسبقة، وتاريخ الجولة.

## 4) بروتوكول إخفاء الهوية (شرط مسبق غير قابل للتفاوض)

1. قص/تغطية أي اسم مريض/طبيب/رقم ملف/تاريخ كامل يدخل فيه تاريخ ميلاد — قبل دخول المجلد.
2. إعادة ترقيم الملفات بمعرفات عشوائية (`b200_0001..b200_0200`) بلا أي ارتباط بالمصدر.
3. ملف manifest يحفظ mapping الأصل — **محلي فقط، خارج أي مستودع**.
4. فحص نهائي آلي (OCR سريع على كل صورة + regex لأسماء/أرقام) قبل اعتماد المجموعة.

## 5) بنية المخرجات والسكربت

```
benchmark_b200/
  images/{printed_clean,printed_degraded,hand_easy,hand_hard,mixed}/
  gt_a/ gt_b/ gt_final/
  manifest.local.json   # محلي فقط
  results/<engine>-<date>/  (cer.csv, wer.csv, terms.csv, run_config.json)
```

الهيكل التنفيذي: `omni-medical-suite/scripts/build_benchmark.py` (فرع skeleton منفصل —
توليد التقسيم، فحص الإخفاء، حساب CER/WER بوظائف نقية مُختبرة).

## 6) معيار الإنجاز

وثيقة معتمدة الصياغة (هذه) + سكربت هيكلي يجتاز اختبارات وحدة على بيانات اصطناعية فقط +
بداية جمع الطبقات. **قياس أول نتيجة CER على المجموعة = بوابة المرحلة 3 في الخارطة الموحدة.**
