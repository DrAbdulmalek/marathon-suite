## 2. ما يتغير **يوم إدخال أول بيانات حقيقية** (قائمة التغيير الملزمة)

1. **السحابة**: `OMNI_ALLOW_CLOUD` يبقى **مغلقًا** إلا بموافقة موثقة لكل نشر على حدة، مع:
   تسجيل `cost_estimate_usd` إلزاميًا (الحقل موجود في العقد/adapter)، وحجب أي نص مريض عن
   مزود خارجي إلا بعد **إزالة تحديد الهوية** الموثقة (§3-T1: إلزامية قبل أي benchmark).
2. **التسجيل (PII)**: أي log قد يحمل نصًا من المستند يُستبدل بحشوه: `len(text)` + `sha256` +
   معرف العينة — **لا نص خام في logs مطلقًا**. `raw_text` يُخزن محليًا فقط (LOCAL_ONLY) وبصلاحيات ملف مقيدة.
3. **التخزين**: حفظ محلي إلزامي لمخرجات المريض (مسار golden path الحالي) — لا رفع لأي
   مستودع عام أو حزمة تدريب؛ `omni-handwriting-samples-private` (خاص) هو المستقبل الوحيد
   المسموح بعد موافقة صريحة.
4. **سلسلة الإثبات**: كل نتيجة تحمل `pdf_sha256` + صف provenance (نُفذ في #185: سياسة تطبيع
   الطرفين) — يبقى شرط قبول للقياس الطبي.
5. **بوابة الأسرار تُشدد**: قبل أول بيانات حقيقية يضاف نمط فحص PII (أرقام ملفات/هويات) إلى
   `scan_diff_secrets.py` — فئة منفصلة عن الاعتمادات وفق توثيق السكربت نفسه.
6. **التراجع**: التبديل إلى الوضع الحقيقي يتم بفرع إعدادات + PR موثق (Level B) — ولا يُنفَّذ
   داخل أي Sprint دون بند مالك صريح في قائمة القرارات (بند مستقبلي: OD-REAL-DATA-01).

## 3. ما لم يُنفَّذ بعد (أمانة)

- تعديلات تسجيل PII أعلاه **مصممة وغير منفذة** (لا بيانات حقيقية موجودة — لا استعجال).
- فحص LOCAL_ONLY الشبكي القوي (S2-T4) لم يُنفذ بعد؛ لا تُدّعى عزلية شاملة من طبقة socket وهمية.
