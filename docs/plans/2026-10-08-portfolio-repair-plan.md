## المرحلة 2: المسار الذهبي (6-8 أسابيع)

### 2.1 تعريف المسار الواحد

```
صورة وصفة → OCR/HTR → تصحيح لغوي → عرض الطبيب → تصحيح بشري → حفظ آمن → بيانات تدريب
```

هذا هو **Golden Path**. كل شيء خارجه = مؤجل.

### 2.2 شروط القبول للمسار

| المرحلة | الشرط | القياس |
|---------|-------|--------|
| دخول | طبيب يفتح التطبيق | < 10 ثوانٍ حتى جاهز |
| OCR | صورة → نص | CER < 15% على handwritten |
| تصحيح | اقتراح تصحيحات | precision > 80% |
| عرض | الطبيب يرى النص | < 2 ثانية |
| تعديل | تصحيح بشري | يعمل دون إعادة تحميل |
| حفظ | تخزين محلي مشفّر | لا اتصال خارجي |
| تغذية | التصحيح يُحفظ | dataset منظم |

### 2.3 حسم الازدواجيات

- `sync-github` vs `repo-sync-toolkit` → أرشفة الأول نهائيًا.
- كل OCR engine غير مستخدم في المسار → تعليق التطوير.
- كل UI غير المسار (Gradio, PyQt6, Next.js) → اختر واحدًا. البقية تُعلَّق.

**المخرج:** تطبيق واحد، مسار واحد، 3 أوامر تشغيل كحد أقصى.
