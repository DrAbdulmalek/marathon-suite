# ماراثون العظام — حملة الجمع والنشر إلى @ortho_homs

## الهدف
سحب الجديد دوريًا من مصادر طب العظام (تيليجرام + ويب) ونشره في قناة الهدف
`@ortho_homs` مع الإسناد، بلا تكرار، وبلا تدخل يدوي بعد الإعداد — ثم تمرير
ما يحتاج ترجمة عبر جسر marathon-suite (OCR → RTL → TM → مسرد → خطة بشرية).

## الملفات
| ملف | دوره |
|------|------|
| `campaign.yaml` | تعريف الماراثون: الهدف، الجدولة (كل 6 ساعات)، قواعد التكرار والنشر، المنفّذ |
| `sources.yaml` | سجل مصادر تيليجرام: 38 مصدرًا (36 نشطًا، 10 منها مصادر فرعية D2) + المستبعَد |
| `web_sources.yaml` | طبقة الويب: مكتبة نور (D3) + TED SRT + 20 صفحة جامعية سورية |

## دورة التشغيل (كل 6 ساعات)
1. **سحب** `new_only_since_last_cursor` من كل مصدر نشط — المؤشرات حالة تشغيل
   محلية (خارج git بحسب اتفاقية المستودع).
2. **إزالة التكرار** بالمفتاح `(source_handle, message_id)` — الحارس المركزي
   `sent_index` في tg-campaign-toolkit.
3. **نشر** إلى `@ortho_homs` بنمط `forward_with_attribution`.
4. **ترجمة اختيارية**: المحتوى ثنائي اللغة يمر عبر
   `marathon_suite.bridge.build_translation_plan` — المباراة التامة فقط
   تُعتمد آليًا، وغير ذلك `needs_human=True`.

## المنفّذ
`tg-campaign-toolkit → scripts/ortho/tg_forward_ortho.py`
- بيانات الاعتماد من `.secrets/` وقت التشغيل فقط — لا أسرار في المستودع.
- إعداد الاستيعاب التفصيلي: `tg-campaign-toolkit → campaigns/ortho/data/ingest_config.json`.

## طبقة الويب (D3)
- **مكتبة نور** (`?search_for=قاموس`): تنزيل كل ما يفيد مستودع الطب، ومستودع
  الترجمة (قواميس)، وبيانات تدريب نماذج الذكاء الاصطناعي — الاكتشاف الحالي
  34 كتابًا في `tg-campaign-toolkit → campaigns/noor/data/`.
- **TED SRT**: ترجمات موازية EN↔AR تغذي translation-core.
- **صفحات الجامعات السورية** (فيسبوك/مواقع): أدلة الكتب الجامعية الطبية.

## الصدق والسلامة
- مصدر «نشط» بلا handle/url → يُخفَّض إلى `inactive` عند التحميل مع سبب مسجَّل
  (`downgraded_reason`) — لا صمت ولا اختلاق.
- المعرّفات الداخلية (`access_hash`, `tg_id`) تُسقَط من السجل المنشور؛
  الهوية بالـhandle وحدها.
- القناتان المستبعَدتان موثّقتان مع السبب في `sources.yaml → excluded`.
